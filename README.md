# Rehab Contract Dashboard

Power BI report for an outpatient rehabilitation clinic and rehabilitation unit: **NFZ contract fulfilment, clinic workload and patient no-shows**.

> **All data in this repository is synthetic.** It was generated by a script to mirror the structure and typical proportions of real rehabilitation data. It contains no real patients, staff or financial figures.

## Business questions

1. **Contract fulfilment:** how many contract points (and PLN) have the clinic and the unit delivered, month by month and year to date, compared with the plan?
2. **Workload:** how many patients did each doctor see, when, and in which unit (children / adults)?
3. **No-shows:** what share of visits did not take place, and what are the top 3 reasons (rescheduled, no-show, etc.)?

## Data model (star schema)

| Table | Type | Content |
|---|---|---|
| `Visits` | fact | visit date, patient, doctor, unit, visit type, status, no-show reason |
| `Procedures` | fact | procedures performed per visit, quantity |
| `ContractPlan` | fact | planned points and point price per unit and month |
| `Calendar` | dimension | date, month, quarter, year |
| `Doctor` | dimension | role, unit |
| `Unit` | dimension | clinic / rehabilitation unit, children / adults |
| `Procedure` | dimension | code, name, points |
| `Patient` | dimension | age group, sex (synthetic) |
